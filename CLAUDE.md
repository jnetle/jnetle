## Repository Purpose

This is the `jnetle/jnetle` GitHub profile repository. The `README.md` at the root is rendered on the GitHub profile page at github.com/jnetle.

## Structure

- `README.md` — the profile page content, displayed publicly on GitHub
- `docs/` — static portfolio site served by GitHub Pages at https://jnetle.github.io/jnetle/ (`index.html` + `fonts/`, `img/`, `uploads/` résumé PDF)

## Development

No build, lint, or test commands — this is a Markdown-only repository. Edit `README.md` directly to update the profile, or `docs/index.html` to update the portfolio site (preview with `python3 -m http.server -d docs`).
